\# SpringGenie



SpringGenie is a desktop Java application built with \*\*JavaFX\*\* that helps developers quickly scaffold Spring Boot components like:



\- ✅ Entities

\- ✅ Repositories

\- ✅ Services

\- ✅ Controllers



\## Features



\- JavaFX GUI using FXML

\- SceneBuilder support

\- Modular structure with clean controller logic

\- Ready for code generation logic
